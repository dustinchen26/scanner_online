# scanner_online

● online : https://dustinchen26.github.io/scanner_online

## How to use
```
上傳照片，可拉伸四個角填滿
類似APP "Lens" 或是 "掃描全能王"

✅ 修改重點
•	iPhone LINE 不再顯示任何警告：您實測可以正常下載，故我們完全移除了 iPhone LINE 的提示，畫面與 Chrome 一樣乾淨。
•	僅 Android LINE 保留警告與遮罩：因為 Samsung LINE 確實無法下載，我們仍為 Android LINE 用戶提供「本頁面顯示圖片 + 分享/截圖」的解決方案。
•	保留「切換模式」按鈕：萬一 Android LINE 自動偵測失靈，用戶仍可手動強制遮罩模式。

```
